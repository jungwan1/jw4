1.

뜻: 이거 얼마예요? / 이거 사고 싶어요.
러시아어Ско́лько э́то сто́ит? / Я хочу́ э́то купи́ть.
한글 발음스꼴까 에따 스또잇? / 야 하추 에따 꾸삐찌.

сто́ить는 "값이 ~이다", купи́ть는 "사다"예요.

2.

뜻: 카드로 내도 돼요? / 현금으로 내도 돼요?
러시아어Мо́жно плати́ть ка́ртой? / Мо́жно плати́ть нали́чными?
한글 발음모쥬나 쁠라찌찌 까르따이? / 모쥬나 쁠라찌찌 날리치늬미?

Мо́жно + 동사 원형 = "~해도 돼요?"예요. ка́рта → ка́ртой는 "카드로"예요.

3.

뜻: 이거 비싸요! / 이거 싸요.
러시아어Э́то до́рого! / Э́то дёшево.
한글 발음에따 도라가! / 에따 죠쉬바.

до́рого(비싸요)와 дёшево(싸요)는 반대말이에요.

4.

뜻: 좀 더 싸게 돼요?
러시아어Мо́жно подеше́вле?
한글 발음모쥬나 빠지셰블례?

시장에서 값을 깎을 때 써요.

5.

뜻: 보여 주세요. / 봉투 주세요.
러시아어Покажи́те, пожа́луйста. / Мо́жно паке́т?
한글 발음빠까쥐쩨, 빠잘스타. / 모쥬나 빠꼣?

Покажи́те는 показа́ть(보여 주다)의 부탁하는 말이에요.

6.

뜻: 도와드릴까요? / 그냥 구경하는 거예요. / 이걸로 할게요.
러시아어Вам помо́чь? / Я про́сто смотрю́. / Я беру́ э́то.
한글 발음밤 빠모치? / 야 쁘로스따 스마트류. / 야 비루 에따.

가게 점원이 Вам помо́чь?라고 물으면 이렇게 대답해요. беру́는 брать(가져가다, 사다)에서 왔어요.

7.

뜻: 메뉴 주세요. / 계산서 주세요.
러시아어Мо́жно меню́? / Счёт, пожа́луйста.
한글 발음모쥬나 미뉴? / 숏, 빠잘스타.

식당에서 가장 많이 쓰는 두 마디예요.

8.

뜻: 물 주세요. / 저는 물 주세요.
러시아어Во́ду, пожа́луйста. / Мне, пожа́луйста, во́ду.
한글 발음보두, 빠잘스타. / 므녜, 빠잘스타, 보두.

вода́가 "~을" 자리에 오면 во́ду가 돼요.

9.

뜻: 물을 사고 싶어요. / 물 마시고 싶어요.
러시아어Я хочу́ купи́ть во́ду. / Я хочу́ пить во́ду.
한글 발음야 하추 꾸삐찌 보두. / 야 하추 삐찌 보두.

хочу́ + 동사 원형 = "~하고 싶어요"예요.

10.

뜻: 뭐 마시고 싶어요? / 너 커피 마시고 싶어?
러시아어Что вы хоти́те пить? / Ты хо́чешь пить ко́фе?
한글 발음쉬또 븨 하찌쩨 삐찌? / 띄 호체쉬 삐찌 꼬폐?

хоте́ть 변화: хочу́ / хо́чешь / хо́чет / хоти́м / хоти́те / хотя́т.

11.

뜻: 응, 마시고 싶어. / 응, 커피 원해.
러시아어Да, я хочу́ пить. / Да, я хочу́ ко́фе.
한글 발음다, 야 하추 삐찌. / 다, 야 하추 꼬폐.

хочу́ 뒤에 동사도, 물건도 바로 올 수 있어요.

12.

뜻: 아직 몰라요.
러시아어Я ещё не зна́ю.
한글 발음야 이쑈 니 즈나유.

ещё와 до сих по́р는 "아직(까지)"이에요.

13.

뜻: 헷갈려요. / 단어가 헷갈려요. / 힘들어요.
러시아어Я запу́тался. / Я пу́таю слова́. / Мне тру́дно.
한글 발음야 자뿌딸샤. / 야 뿌따유 슬라바. / 므녜 뜨루드나.

여자는 Я запу́талась.라고 해요.

14.

뜻: 너는 돈을 벌어. / 너 돈 많이 벌어?
러시아어Ты зараба́тываешь де́ньги. / Ты мно́го зараба́тываешь?
한글 발음띄 자라바띄바예쉬 졘기. / 띄 므노가 자라바띄바예쉬?

зараба́тывать = 돈을 벌다예요.

15.

뜻: 화났어. / 화나. / 너 화났어? / 화내지 마!
러시아어Я зол. / Я злюсь. / Ты зли́шься? / Не злись!
한글 발음야 졸. / 야 즐류스. / 띄 즐리쉬샤? / 니 즐리스!

зли́ться 변화: злюсь / зли́шься / зли́тся / зли́мся / зли́тесь / зля́тся.

16.

뜻: 이거 짜증 나!
러시아어Меня́ э́то бе́сит!
한글 발음미냐 에따 볘싯!

직역하면 "이게 나를 화나게 해"예요.

17.

뜻: 두 명 자리 주세요. / 아주 맛있어요! / 맛있게 드세요!
러시아어Стол на двои́х, пожа́луйста. / О́чень вку́сно! / Прия́тного аппети́та!
한글 발음스똘 나 드바이흐, 빠잘스타. / 오친 프꾸스나! / 쁘리야뜨나바 아삐찌따!

на двои́х = 두 사람용이에요.

18.

뜻: 왜 그런지 모르겠지만…
러시아어Не зна́ю почему́, но...
한글 발음니 즈나유 빠치무, 노...

말을 시작할 때 자연스럽게 쓰는 말이에요.

19.

뜻: 지하철 어디예요? / 호텔까지 어떻게 가요?
러시아어Где метро́? / Как дое́хать до оте́ля?
한글 발음그졔 미뜨로? / 깍 다예하찌 다 아뗄랴?

до 뒤에서 оте́ль → оте́ля가 돼요.

20.

뜻: 직진, 왼쪽, 오른쪽
러시아어Пря́мо, нале́во, напра́во
한글 발음쁘랴마, 날례바, 나쁘라바

길을 물으면 꼭 듣는 세 단어예요.

21.

뜻: 전화기를 도둑맞았어요! / 가방을 빼앗겼어요.
러시아어У меня́ укра́ли телефо́н! / У меня́ отня́ли су́мку.
한글 발음우 미냐 우끄랄리 찔리폰! / 우 미냐 앗냘리 숨꾸.

укра́сть = 훔치다, отня́ть = 빼앗다예요.

22.

뜻: 그가 나한테서 전화기를 빼앗았어요. / 누군가가 내 전화기를 훔쳤어요.
러시아어Он о́тнял у меня́ телефо́н. / Кто́-то укра́л мой телефо́н.
한글 발음온 오뜨날 우 미냐 찔리폰. / 끄또따 우끄랄 모이 찔리폰.

кто́-то는 "(특정한) 누군가"예요.

23.

뜻: 누구 한국어 하는 사람 있어요? / 누가 좀 도와주세요!
러시아어Кто́-нибудь говори́т по-коре́йски? / Помоги́те, кто́-нибудь!
한글 발음끄또니부찌 가바릿 빠까례이스끼? / 빠마기쩨, 끄또니부찌!

кто́-нибудь는 질문이나 부탁에서 "누구든, 아무나"예요.

24.

뜻: 한 번은 모스크바에 있었어요.
러시아어Одна́жды я был в Москве́.
한글 발음아드나쥬듸 야 븰 브 마스끄볘.

одна́жды = 어느 날, 한 번은이에요.

25.

뜻: 나는 그에게 돈을 줬어요. / 그한테 전화해 주세요. / 나는 그를 알아요.
러시아어Я дал ему́ де́ньги. / Позвони́те ему́, пожа́луйста. / Я зна́ю его́.
한글 발음야 달 이무 졘기. / 빠즈바니쩨 이무, 빠잘스타. / 야 즈나유 이보.

он 그는 / его́ 그를 / ему́ 그에게. "~에게"는 мне 나에게, тебе́ 너에게, ей 그녀에게예요.

26.

뜻: 예약했어요. / 방이 필요해요. / 아침 식사는 몇 시예요?
러시아어У меня́ бронь. / Мне ну́жен но́мер. / Во ско́лько за́втрак?
한글 발음우 미냐 브로니. / 므녜 누쥔 노미르. / 바 스꼴까 자프뜨락?

호텔에서는 но́мер가 "방"이에요.

27.

뜻: 나는 한 달 전에 러시아어 공부를 시작했어요.
러시아어Я на́чал учи́ть ру́сский ме́сяц наза́д.
한글 발음야 나찰 우치찌 루스끼 몌샤츠 나자트.

ме́сяц наза́д = 한 달 전이에요.

28.

뜻: 4월에 / 금요일에 / 봄에 / 여름에
러시아어в апре́ле / в пя́тницу / весно́й / ле́том
한글 발음브 아쁘렐례 / 프 뺘뜨니쭈 / 비스노이 / 례땀

요일: понеде́льник, вто́рник, среда́, четве́рг, пя́тница, суббо́та, воскресе́нье. 계절: весна́ 봄, ле́то 여름, о́сень 가을, зима́ 겨울.

29.

뜻: 걸어왔어? / 응, 걸어서. / 아니, 지하철로. / 아니, 택시로.
러시아어Ты пришёл пешко́м? / Да, пешко́м. / Нет, на метро́. / Нет, на такси́.
한글 발음띄 쁘리숄 삐쉬꼼? / 다, 삐쉬꼼. / 녯, 나 미뜨로. / 녯, 나 딱시.

여자에게는 Ты пришла́ пешко́м?예요.

30.

뜻: 도움이 필요해요. / 의사를 불러 주세요. / 머리가 아파요.
러시아어Мне нужна́ по́мощь. / Вы́зовите врача́, пожа́луйста. / У меня́ боли́т голова́.
한글 발음므녜 누쥬나 뽀마쉬. / 븨자비쩨 브라차, 빠잘스타. / 우 미냐 발릿 갈라바.

아픈 곳은 У меня́ боли́т + 아픈 곳으로 말해요.

31.

뜻: 이건 비빔밥이에요. 밥, 채소, 계란을 넣고 섞어서 먹어요.
러시아어Э́то пибимпа́п. Кладём рис, о́вощи, яйцо́, переме́шиваем и еди́м.
한글 발음에따 삐빔빱. 끌라좀 리스, 오바쉬, 이이초, 삐리메쉬바옘 이 이짐.

Кладём 넣어요, переме́шиваем 섞어요, еди́м 먹어요예요.

32.

뜻: 내년 6월에 러시아에 가요. / 여름에 모스크바가 나를 기다려요.
러시아어В сле́дующем году́ в ию́не я пое́ду в Росси́ю. / Ле́том меня́ ждёт Москва́.
한글 발음프 슬례두유쉠 가두 브 이유녜 야 빠예두 브 라씨유. / 례땀 미냐 즈죳 마스끄바.

в сле́дующем году́ = 내년에, в ию́не = 6월에예요.

33.

뜻: 나는 러시아어를 배운 지 벌써 2년 됐어요.
러시아어Я учу́ ру́сский уже́ два го́да.
한글 발음야 우추 루스끼 우줴 드바 고다.

러시아어는 "벌써 2년째 배우고 있어요"처럼 현재형으로 말해요.

34.

뜻: 붉은 광장에 해가 빛나요. 그리고 오늘 나는 정말 좋아요!
러시아어На Кра́сной пло́щади све́тит со́лнце. И мне сего́дня о́чень хорошо́!
한글 발음나 끄라스나이 쁠로샤지 스볘찟 손쩨. 이 므녜 시보드냐 오친 하라쇼!

Мне хорошо́ = 나는 기분이 좋아요예요.

35.

뜻: 피곤했지만 그래도 집회에 갔어요. / 하지만 그렇지 않아요.
러시아어Я уста́л, одна́ко я пошёл на встре́чу. / Одна́ко э́то не так.
한글 발음야 우스딸, 아드나까 야 빠숄 나 프스뜨례추. / 아드나까 에따 니 딱.

одна́ко는 но보다 격식 있는 "하지만"이에요.

36.

뜻: (노래 75) 여기 제가 있어요, 나의 하느님, 저를 보내 주세요. / 저는 준비됐어요! 저를 보내 주세요.
러시아어Вот я, мой Бог, пошли́ меня́. / Я гото́в! Пошли́ меня́.
한글 발음봇 야, 모이 보흐, 빠쉴리 미냐. / 야 가또프! 빠쉴리 미냐.

여자는 Я гото́ва!예요.

37.

뜻: (노래 84) 우리는 도우러 서둘러 가요, 가장 필요한 곳에 있을 거예요. / 도움을 기다리는 곳으로 서둘러 가요.
러시아어На по́мощь мы спеши́м, бу́дем там, где всего́ нужне́й. / Спеши́м туда́, где по́мощь ждут.
한글 발음나 뽀마쉬 믜 스삐쉼, 부짐 땀, 그졔 프시보 누쥬녜이. / 스삐쉼 뚜다, 그졔 뽀마쉬 즈둣.

спеши́ть = 서두르다예요.

38.

뜻: (노래 57) 그들도 하느님의 벗이 될 수 있어요. / 나는 러시아어로 말할 수 있어요.
러시아어Друзья́ми Бо́га мо́гут стать они́. / Я могу́ говори́ть по-ру́сски.
한글 발음드루지야미 보가 모굿 스따찌 아니. / 야 마구 가바리찌 빠루스끼.
