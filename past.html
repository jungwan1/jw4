지난 공부

뜻: 머리가 아파요. / 가까운 약국이 어디예요? / 감기약이 필요해요. / 병원에 가야 해요.
러시아어У меня́ боли́т голова́. / Где ближа́йшая апте́ка? / Мне ну́жно лека́рство от просту́ды. / Мне ну́жно к врачу́.
한글 발음우 미냐 발릿 걸라바. / 그데 블리자이샤야 아프쩨카. / 므녜 누즈나 리카르스트바 앗 쁘라스뚜드이. / 므녜 누즈나 크 브라추.

апте́ка = 약국, лека́рство = 약, врач = 의사, боле́ть = 아프다, ка́шлять = 기침하다. лека́рство от просту́ды = 감기약.

뜻: 오늘 날씨 어때요? / 오늘 너무 추워요. / 나 추워졌어요. / 우리 산책할까요?
러시아어Кака́я сего́дня пого́да? / Сего́дня о́чень хо́лодно. / Я замёрз. / Дава́й погуля́ем?
한글 발음카카야 시보드냐 빠고다. / 시보드냐 오친 홀라드나. / 야 자묘르스. / 다바이 빠굴랴옘?

пого́да = 날씨, зонт = 우산, гуля́ть = 산책하다. 여자가 말하면 замёрз → замёрзла. 그냥 «Хо́лодно!» / «Мне хо́лодно.»라고 해도 돼요.

뜻: 나는 놀랄 거야. / 너는 놀랄 거야. / 그녀는 놀랄 거야. / 놀라지 마! / 그녀가 알면 놀랄 거야.
러시아어Я испуга́юсь. / Ты испуга́ешься. / Она́ испуга́ется. / Не испуга́йся! / Она́ испуга́ется, е́сли узна́ет.
한글 발음야 이스뿌가유스. / 띄 이스뿌가예쉬샤. / 아나 이스뿌가옛짜. / 니 이스뿌가이샤! / 아나 이스뿌가옛짜, 예슬리 우즈나옫.

미래: испуга́юсь, испуга́ешься, испуга́ется, испуга́емся, испуга́етесь, испуга́ются.

뜻: 잘 놀라요. / 지금 무서워요.
러시아어Я пуга́юсь. / Я бою́сь. / Мне стра́шно.
한글 발음야 뿌가유스. / 야 바유스. / 므녜 스트라슈나.

испуга́ться는 완료라서 현재형이 없어요. 과거는 испуга́лся, 미래는 испуга́юсь. 지금 무섭다면 бою́сь나 Мне стра́шно를 써요.

뜻: 어렸을 때 저는 개를 무서워했어요. / 땅이 흔들렸을 때 깜짝 놀랐어요.
러시아어В де́тстве я боя́лся соба́к. / Я испуга́лся, когда́ земля́ затрясла́сь.
한글 발음브 젯스트베 야 바얄샤 사박. / 야 이스뿌갈샤, 카그다 짐랴 자뜨리슬라스.

боя́лся는 계속 무서워했다는 뜻이고, испуга́лся는 순간 깜짝 놀라 무서웠다는 뜻이에요. 여자면 боя́лась / испуга́лась.

뜻: 어젯밤에 지진이 났어요. 무서웠어요.
러시아어Вчера́ но́чью бы́ло землетрясе́ние. Я испуга́лся. / Мне бы́ло стра́шно.
한글 발음브체라 노츄 브일라 짐리뜨리세니예. 야 이스뿌갈샤. / 므녜 브일라 스트라슈나.

ночь → но́чью = 밤에. бою́сь는 지금 무섭다는 말, испуга́лся는 그때 무서웠다는 말이에요.

뜻: 땅이 흔들려요. / 땅이 흔들렸어요. / 지진이 났어요.
러시아어Земля́ трясётся. / Земля́ трясла́сь. / Бы́ло землетрясе́ние.
한글 발음짐랴 뜨리됸짜. / 짐랴 뜨리슬라스. / 브일라 짐리뜨리세니예.

землетрясе́ние = 지진. трясти́сь = 흔들리다.

뜻: 밥을 넣고, 야채를 넣어요. / 다 넣고 섞어요.
러시아어Кладём рис и о́вощи. / Кладём всё и переме́шиваем.
한글 발음끌라죰 리스 이 오바쉬. / 끌라죰 프쇼 이 뻬리메쉬바옘.

кладём = 넣어요 (класть). переме́шиваем = 섞어요 (переме́шивать).

뜻: 재료를 넣어서 섞어서 드세요. / 다 섞어서 드세요!
러시아어Положи́те ингредие́нты, перемеша́йте и ешьте. / Всё перемеша́йте и ешьте!
한글 발음빨라지쩨 인그리디옌뜨이, 뻬리미샤이쩨 이 예쉬쩨. / 프쇼 뻬리미샤이쩨 이 예쉬쩨!

положи́ть = 넣다, перемеша́ть = 섞다. 존댓말 명령형이에요.

뜻: 가는 길에 비싼 카페를 봤지만, 다른 데로 갔어요. / 카페에서 커피를 마셔요. / 포기 안 해, 한 번 더 해볼게!
러시아어По доро́ге я ви́дел доро́гое кафе́, но пошёл в друго́е. / Я пью ко́фе в кафе́. / Я не сдаю́сь, я попро́бую ещё раз!
한글 발음빠 다로게 야 비젤 도로고예 카페, 노 빠숄 브 드루고예. / 야 삐유 코페 브 카페. / 야 니 즈다유스, 야 빠쁘로부유 이쇼 라스!

자주 헷갈리는 말: доро́га(길) / до́рого(비싸요) / дорого́й(비싼) / друго́й(다른). ко́фе는 커피, кафе́는 카페. ви́жу는 봐요, бегу́는 뛰어요.

뜻: 여기 줄 길다. 다른 카페 가자!
러시아어Здесь дли́нная о́чередь. Пойдём в друго́е кафе́!
한글 발음즈데스 들린나야 오체릿. 빠이다옴 브 드루고예 카페!

о́чередь는 여성 명사라서 дли́нная / больша́я를 써요. друго́й는 다른, дорого́й는 비싼이에요. кафе́는 중성이라 в друго́е кафе́.

뜻: 줄 마지막이에요? / 줄 서 있어요. / 줄 길어요. / 이제 제 차례예요.
러시아어Вы после́дний? / Я стою́ в о́череди. / Тут больша́я о́чередь. / Сейча́с моя́ о́чередь.
한글 발음브이 파슬레드니? / 야 스타유 브 오체리지. / 뚜뜨 발샤야 오체릿. / 시차스 마야 오체릿.

о́чередь = 줄, 차례. больша́я о́чередь와 дли́нная о́чередь 둘 다 «줄이 길다»는 뜻으로 써요.

뜻: 역까지 어떻게 가요? / 다음 정류장이 어디예요? / 캐리어 맡겨도 돼요? / 아침은 몇 시예요?
러시아어Как добра́ться до вокза́ла? / Кака́я сле́дующая остано́вка? / Мо́жно оста́вить чемода́н? / Во ско́лько за́втрак?
한글 발음칵 다브라짜 다 박잘라? / 카카야 슬레두슈샤야 아스타노프카? / 모즈나 아스타비찌 치마단? / 바 스콜카 자프트락?

чемода́н = 캐리어, остано́вка = 정류장, забыва́ть = 잊다, пока́зывать = 보여 주다.

뜻: 잘 골랐어. 여기 진짜 맛있다!
러시아어Ты хорошо́ вы́брала. Здесь о́чень вку́сно!
한글 발음띄 하라쇼 브이브랄라. 즈데스 오친 프꾸스나!

남자가 골랐으면 вы́брал. вку́сно는 [프꾸스나]처럼 들려요.

뜻: 고르셨어요? / 아직 고르는 중이에요. / 고를 게 많네요! / 잘 골랐어. / 좋은 선택!
러시아어Вы уже́ вы́брали? / Я ещё выбира́ю. / У вас большо́й вы́бор! / Ты хорошо́ вы́брал(а). / Хоро́ший вы́бор!
한글 발음브이 우제 브이브라리? / 야 이쇼 비비라유. / 우 바스 발쇼이 브이바르! / 띄 하라쇼 브이브랄(라). / 하로쉬 브이바르!

выбира́ть는 고르는 중, вы́брать는 이미 고름. вы́бор = 선택.

뜻: 다른 재킷 주세요. / 취향이 달라요. / 뭐가 달라요?
러시아어Дай мне другу́ю ку́ртку. / У нас ра́зные вку́сы. / Чем э́то отлича́ется?
한글 발음다이 므녜 드루구유 쿠르트쿠. / 우 나스 라즈늬예 프꾸스이. / 쳄 에따 아틀리차엣짜?

друго́й = 다른 것, ра́зный = 서로 다른, отлича́ться = 다르다. дари́ть는 선물하다라서 헷갈리지 마세요.

뜻: 너무 비싸요! / 가는 길에 아주 비싼 재킷을 샀어요.
러시아어Э́то о́чень до́рого! / По доро́ге я купи́л о́чень дорогу́ю ку́ртку.
한글 발음에따 오친 도로가! / 빠 다로게 야 꾸쁠 오친 도로구유 쿠르트쿠.

доро́га = 길 (강세가 가운데), до́рого = 비싸요 (강세가 앞), дорого́й = 비싼/소중한.

뜻: 집에 가는 길에 커피를 샀어요. / 좋은 여행 되세요!
러시아어По доро́ге домо́й я купи́л ко́фе. / Счастли́вого пути́!
한글 발음빠 다로게 다모이 야 꾸쁠 코페. / 샤슬리바바 뿌찌!

доро́га는 실제 길, путь는 여정·여행 같은 길이에요.

뜻: 입어 봐도 돼요? / 이거 얼마예요? / 카드로 계산돼도 돼요? / 영수증 주세요.
러시아어Мо́жно приме́рить? / Ско́лько э́то сто́ит? / Мо́жно заплати́ть ка́ртой? / Да́йте, пожа́луйста, чек.
한글 발음모즈나 프리메리찌? / 스콜카 에따 스토잇? / 모즈나 자플라띠찌 카르타이? / 다이쩨, 빠잘루이스따, 첵.

биле́т = 표, доро́га = 길, купи́ть = 사다, потеря́ть = 잃어버리다, опа́здывать = 늦다.

뜻: 뛰면서 노래를 들어요.
러시아어Я слу́шаю пе́сни на бегу́. / Я слу́шаю пе́сню на бегу́.
한글 발음야 슬루샤유 뻬스니 나 비구. / 야 슬루샤유 뻬스뉴 나 비구.

пе́сня → пе́сню(하나, 대격) / пе́сни(여러 개). на бегу́ = 뛰면서.

뜻: 나는 뛰면서 커피를 마셔요. / 뛰어가요! / 지금 가요!
러시아어Я бегу́ и пью ко́фе. / Я бегу́! / Бегу́-бегу́!
한글 발음야 비구 이 삐유 코페. / 야 비구! / 비구-비구!

иду́는 걸어간다, бегу́는 뛰어간다. на бегу́는 뛰면서·급하게, на ходу́는 걸으면서.

뜻: 가면서 커피를 마셔요.
러시아어Я иду́ и пью ко́фе. / Я пью ко́фе на ходу́.
한글 발음야 이두 이 삐유 코페. / 야 삐유 코페 나 하두.

на ходу́ = 걸으면서, 가면서.

뜻: 걸으면서 먹어요. / 가는 길에 먹어요. / 가면서 먹을게!
러시아어Я иду́ и ем. / Я ем на ходу́. / Я ем по доро́ге. / Я пое́м на ходу́!
한글 발음야 이두 이 옘. / 야 옘 나 하두. / 야 옘 빠 다로게. / 야 파옘 나 하두!

на ходу́ = 걸으면서, по доро́ге = 가는 길에.

뜻: 우리는 해야 해. / 우리 이거 해야 해요.
러시아어Мы должны́ э́то сде́лать. / Нам на́до. / Нам ну́жно э́то сде́лать.
한글 발음믜 달즈늬 에따 즈젤라찌. / 남 나다. / 남 누즈나 에따 즈젤라찌.

мне는 나한테, нам은 우리한테예요.

뜻: 한국어는 존댓말이 어려워요. / 한국에는 존댓말이 있어요. / 친구들과는 반말해요.
러시아어В коре́йском языке́ тру́дная ве́жливая речь. / В Коре́е есть ве́жливая речь. / С друзья́ми я говорю́ неформа́льно.
한글 발음브 카레이스캄 이지케 뜨루드나야 베즐리바야 레치. / 브 카레예 예스찌 베즐리바야 레치. / 스 드루지야미 야 가바류 니파르말나.

존댓말 = ве́жливая речь, 반말 = неформа́льная речь. «한국어에서»는 в коре́йском языке́예요.

뜻: 우리 말 놓자! / 반말해도 돼요? / 우리는 존댓말 써요.
러시아어Дава́й на «ты»! / Мо́жно на «ты»? / Мы на «вы».
한글 발음다바이 나 띄! / 모즈나 나 띄? / 믜 나 브이.

반말은 на «ты», 존댓말은 на «вы». 명령형은 Попро́буй! → Попро́буйте!, Не сдава́йся! → Не сдава́йтесь!처럼 -те를 붙여요.

뜻: 포기 안 해! / 포기하지 마! / 해 보세요.
러시아어Я не сдаю́сь! / Не сдава́йся! / Попро́буйте!
한글 발음야 니 즈다유스! / 니 즈다바이샤! / 빠쁘로부이쩨!

сдава́ться = 포기하다. попро́буйте는 «해 보세요, 드셔 보세요»예요.

뜻: 이 음식 먹어 봤어? / 아직 안 먹어 봤어. / 꼭 먹어 볼게!
러시아어Ты уже́ ел э́ту еду́? / Ты про́бовал э́ту еду́? / Я ещё не про́бовал. / Я обяза́тельно попро́бую!
한글 발음띄 우제 옐 에뚜 예두? / 띄 쁘로바발 에뚜 예두? / 야 이쇼 니 쁘로바발. / 야 아비쟈젤나 빠쁘로부유!

여자는 е́ла / про́бовала예요.

뜻: 나 해야 할 게 좀 있어. / 너한테 할 말이 좀 있어. / 너한테 보여 줄 게 좀 있어. / 너 주려고 뭘 좀 가져왔어.
러시아어Мне на́до ко́е-что сде́лать. / Я хочу́ тебе́ ко́е-что сказа́ть. / Я хочу́ тебе́ ко́е-что показа́ть. / Я тебе́ ко́е-что принёс.
한글 발음므녜 나다 꼬예쉬또 즈젤라찌. / 야 하추 찌베 꼬예쉬또 스카잣찌. / 야 하추 찌베 꼬예쉬또 빠카잣찌. / 야 찌베 꼬예쉬또 프리노스.

ко́е-что = 뭔가, 어떤 것. 여자는 принёс → принесла́.

러시아어Ско́лько э́то сто́ит? / Я хочу́ э́то купи́ть.
한글 발음스꼴까 에따 스또잇? / 야 하추 에따 꾸삐찌.

сто́ить는 "값이 ~이다", купи́ть는 "사다"예요.

뜻: 자~, 그럼, 음… / 그래서, 뭐요? / 자, 가자!
러시아어Ну / Ну, что? / Ну, пойдём!
한글 발음누 / 누, 쉬또? / 누, 빠이좀!

Ну는 말 앞에 붙여 분위기를 이어 주는 말이에요.

뜻: 저는 형(남자 형제)한테 가요. / 엄마한테
러시아어Я иду́ к бра́ту. / к ма́ме
한글 발음야 이두 그 브라뚜. / 끄 마몌

к 뒤에서 брат → бра́ту, ма́ма → ма́ме가 돼요.

뜻: 친구한테 가요. / 의사한테 가요.
러시아어Я иду́ к дру́гу. / Я иду́ к врачу́.
한글 발음야 이두 그 드루구. / 야 이두 끄 브라추.

사람한테 갈 때는 к(~한테, ~쪽으로)를 써요. к 뒤에서 друг → дру́гу, врач → врачу́가 돼요.

뜻: 가게에 가요. / 저는 호텔에 가요.
러시아어Я иду́ в магази́н. / Я иду́ в оте́ль.
한글 발음야 이두 브 마가진. / 야 이두 브 아뗄.

장소로 갈 때는 в(~에, ~안으로)를 써요.

뜻: AI한테서 오는 결과를 기다려요.
러시아어Я жду результа́т от ИИ.
한글 발음야 쥬두 리줄따트 앗 이이

от = ~한테서, ИИ = AI예요.

뜻: 어디 사세요?
러시아어Где вы живёте?
한글 발음그졔 븨 쥐뵤쩨?

친구에게는 Где ты живёшь?로 물어요.

뜻: 저는 살아요. / 저는 한국에 살아요. / 저는 서울에 살아요.
러시아어Я живу́. / Я живу́ в Коре́е. / Я живу́ в Сеу́ле.
한글 발음야 쥐부. / 야 쥐부 프 까레예. / 야 쥐부 프 씨울례.

원형은 жить(살다)예요. 사는 곳은 в 뒤에 써요.

뜻: 잠깐만 기다려 주세요! / 기다려!
러시아어Подожди́те, пожа́луйста! / Подожди́!
한글 발음빠다쥐쩨, 빠잘스타! / 빠다쥐!

존댓말은 Подожди́те, 친구에게는 Подожди́예요.

뜻: 저는 기다려요. / 택시 기다려요.
러시아어Я жду. / Я жду такси́.
한글 발음야 쥬두. / 야 쥬두 딱시.

원형은 ждать(기다리다)예요.

뜻: 그거 틀렸어.
러시아어Э́то непра́вильно.
한글 발음에따 니프라빌나

맞으면 Э́то пра́вильно.예요.

뜻: 니가 한 말은 틀렸어. 다른 단어를 써야 해.
러시아어Ты сказа́ла непра́вильно. На́до испо́льзовать друго́е сло́во.
한글 발음띄 스까잘라 니프라빌나. 나다 이스뽈자바찌 드루고예 슬로바.

여자에게는 сказа́ла, 남자에게는 сказа́л예요. На́до + 동사 원형 = "~해야 해"예요.

뜻: 어떤 영화 좋아해요?
러시아어Како́й фильм вы лю́бите?
한글 발음까꼬이 필름 븨 류비쩨?

фильм은 남성이라 како́й예요.

뜻: 저는 영화 보는 걸 좋아해요.
러시아어Я люблю́ смотре́ть кино́.
한글 발음야 류블류 스마트레찌 끼노

люблю́ 뒤에 동사 원형을 붙이면 "~하는 걸 좋아해요"예요.

뜻: 나의 취미는 영화 보기예요.
러시아어Моё хо́бби — смотре́ть фи́льмы. / Моё увлече́ние — кино́.
한글 발음마요 호비 — 스마트레찌 필믜. / 마요 우블리체니예 — 끼노.

хо́бби와 увлече́ние 둘 다 "취미"예요. 둘 다 중성이라 моё를 써요.

뜻: 주의!
러시아어Внима́ние!
한글 발음브니마니예!

주의 표지판에 자주 써 있어요.

뜻: 내가 너한테 미리 말했잖아.
러시아어Я тебя́ предупреди́л. / Я тебя́ предупреди́ла.
한글 발음야 찌뱌 쁘리두쁘리질. / 야 찌뱌 쁘리두쁘리질라.

동사 원형은 предупреди́ть예요. 남자 화자는 предупреди́л, 여자 화자는 предупреди́ла예요.

뜻: 이건 경고예요!
러시아어Э́то предупрежде́ние!
한글 발음에따 쁘리두쁘리쥐제니예!

предупрежде́ние는 "경고"예요.

뜻: дра́ться(주먹으로 싸우다) 인칭 변화
러시아어я деру́сь / ты дерёшься / он дерётся / мы дерёмся / вы дерётесь / они́ деру́тся
한글 발음야 지루스 / 띄 지료쉬샤 / 온 지료짜 / 믜 지렴샤 / 븨 지료쩨스 / 아니 지루짜

과거는 дра́лся, драла́сь, дра́лись예요. 여기도 -ся/-сь가 항상 붙어요.

뜻: ссо́риться(말다툼하다) 인칭 변화
러시아어я ссо́рюсь / ты ссо́ришься / он ссо́рится / мы ссо́римся / вы ссо́ритесь / они́ ссо́рятся
한글 발음야 쏘류스 / 띄 쏘리쉬샤 / 온 쏘리짜 / 믜 쏘림샤 / 븨 쏘리쩨스 / 아니 쏘랴짜

과거는 남자 ссо́рился, 여자 ссо́рилась, 여럿 ссо́рились예요. 먼저 я, ты, мы만 외워도 충분해요.

뜻: 너희는 자주 싸워? / 너 자주 싸워?
러시아어Вы ча́сто ссо́ритесь? / Ты ча́сто ссо́ришься?
한글 발음븨 차스타 쏘리쩨스? / 띄 차스타 쏘리쉬샤?

여러 명이나 존댓말은 Вы, 친구 한 명은 Ты예요. ча́сто는 "자주"예요.

뜻: 저 사람들 (주먹으로) 싸우고 있어요.
러시아어Они́ деру́тся.
한글 발음아니 지루짜

주먹으로 싸우는 것은 дра́ться예요. 말다툼(ссо́риться)과 구별해요.

뜻: 우리 싸웠어요. / 싸우지 마세요!
러시아어Мы поссо́рились. / Не ссо́рьтесь!
한글 발음믜 빠쏘릴리스. / 니 쏘리쩨스!

말다툼은 ссо́риться예요. 끝의 -сь/-ся는 모양이 바뀌어도 따라다녀요.

뜻: 나 아파요.
러시아어Я боле́ю.
한글 발음야 발례유.
뜻: 머리가 아파요.
러시아어У меня́ боли́т голова́.
한글 발음우 미냐 발릿 갈라바.

어디가 아픈지는 У меня́ боли́т… 뒤에 부위를 넣어요. 배는 живо́т(쥐봇).

뜻: 배고파 죽겠어요!
러시아어Я умира́ю от го́лода!
한글 발음야 우미라유 앗 골라다!

원형 умере́ть는 "죽다". 농담으로 많이 써요.

뜻: 당신의 옷이 아름다워요.
러시아어У вас краси́вая оде́жда.
한글 발음우 바스 끄라씨바야 아졔쥐다

у вас는 존댓말, 친구에게는 у тебя́. 더 자연스러운 칭찬은 Вам о́чень идёт! (밤 오친 이죳!) = 정말 잘 어울려요!

뜻: 가장 중요한 건 건강이에요.
러시아어Са́мое гла́вное — здоро́вье.
한글 발음싸마예 글라브나예, 즈다로비예

са́мое гла́вное는 "가장 중요한 건".

뜻: 무엇보다도 고마워요!
러시아어Пре́жде всего́, спаси́бо!
한글 발음쁘례쥐졔 프시보, 스빠씨바!

пре́жде всего́는 "무엇보다도".

뜻: 나는 매일 커피를 마셔요.
러시아어Я пью ко́фе ка́ждый день.
한글 발음야 삐유 꼬페 까쥐듸 졘

ка́ждый день은 "매일".

뜻: 모스크바보다 더 좋은 게 있을까요?
러시아어Что мо́жет быть лу́чше, чем Москва́?
한글 발음쉬또 모젯 븨찌 루치셰, 쳄 마스크바?

끝을 올려서 질문으로 말해요. 서울은 Сеу́л.

뜻: 아는 것보다 더 좋은 게 뭐가 있을까요?
러시아어Что мо́жет быть лу́чше, чем знать?
한글 발음쉬또 모젯 븨찌 루치셰, 쳄 즈나찌?

лу́чше는 хорошо́의 비교형 "더 좋은", чем은 "~보다".

뜻: 그의 수많은 작품들을 연구하면서
러시아어исследу́я его́ многочи́сленные творе́ния
한글 발음이슬례두야 이보 므나가치슬롄늬예 뜨바례니야

его́의 г는 "브"로 읽어요. 책이나 박물관 설명에 나오는 말이에요.

뜻: 나 가야 해요.
러시아어Мне ну́жно идти́.
한글 발음므녜 누쥬나 이찌.
뜻: 택시가 필요해요.
러시아어Мне ну́жно такси́.
한글 발음므녜 누쥬나 딱씨.

Мне ну́жно 뒤에 동사 원형(해야 해요)이나 명사(필요해요).

뜻: 나도 왜 그런지는 모르겠지만…
러시아어Я сам не зна́ю почему́, но…
한글 발음야 쌈 니 즈나유 빠치무, 노…

сам은 "나도, 나 스스로", почему́는 "왜", но는 "하지만".

뜻: 나 지금 운전 중이에요.
러시아어Я веду́ маши́ну.
한글 발음야 비두 마쉬누

지금 운전하는 중일 때는 вести́. 나는 веду́.

뜻: 너 운전해?
러시아어Ты во́дишь маши́ну?
한글 발음띄 보지쉬 마쉬누?

습관처럼 운전하는 것은 води́ть. "나는 차를 운전해요"는 Я вожу́ маши́ну. (야 바쥬 마쉬누).

뜻: 내 발음이 맞아요?
러시아어Моё произноше́ние пра́вильно?
한글 발음마요 쁘라이즈나쉐니예 쁘라빌나?

произноше́ние는 "발음", пра́вильно는 "맞아, 올바르게".

뜻: 내가 너한테 방금 물어본 거야.
러시아어Я про́сто спроси́л тебя́.
한글 발음야 쁘로스따 스쁘라실 찌뱌

спроси́ть는 тебя́를 받아요(тебе́ 아님). 여자 화자면 спроси́ла.

뜻: 아니, 나는 러시아에 가 본 적 없어. 그런데 러시아에 갈 계획이야.
러시아어Нет, я не был в Росси́и. Но я плани́рую пое́хать в Росси́ю.
한글 발음녯, 야 니 빌 브 라시이. 노 야 플라니루유 빠예하찌 브 라시유

위치는 в Росси́и, 방향은 в Росси́ю. 남자는 был, 여자는 была́. 다음 해는 в сле́дующем году́, 지난해는 про́шлый год예요.

뜻: "между"랑 "среди"는 무슨 차이야?
러시아어Кака́я ра́зница ме́жду слова́ми «ме́жду» и «среди́»?
한글 발음까까야 라즈니짜 메즈두 슬라바미 «메즈두» 이 «스리지»?

ме́жду는 둘 사이, среди́는 여럿 가운데예요.

뜻: "видеть"랑 "смотреть"는 무슨 차이야?
러시아어Кака́я ра́зница ме́жду слова́ми «ви́деть» и «смотре́ть»?
한글 발음까까야 라즈니짜 메즈두 슬라바미 «비졔찌» 이 «스마뜨례찌»?

ви́деть는 눈에 들어오는 "보다/보이다", смотре́ть는 일부러 바라보는 거예요.

뜻: 나는 포기 안 해!
러시아어Я не сдаю́сь!
한글 발음야 니 즈다유스!

원형은 сдава́ться예요. 끝의 -ся는 모양이 바뀌어도 따라다녀요.

뜻: 이 음식 먹어 봤어?
러시아어Ты ел э́ту еду́?
한글 발음띄 옐 에뚜 예두?

경험을 물을 때 과거형을 써요. 여자에게는 Ты е́ла э́ту еду́?예요.

뜻: 나 해야 할 게 좀 있어.
러시아어Мне ну́жно ко́е-что сде́лать.
한글 발음므녜 누쥬나 꼬예쉬또 즈젤라찌

Мне ну́жно 뒤에는 동사 원형이나 물건이 와요. ко́е-что는 "뭔가 좀"이고, что-то는 "뭔지 모를 것"에 더 가까워요.

뜻: 그 일을 해야만 러시아에 갈 수 있어.
러시아어Я смогу́ пое́хать в Росси́ю, то́лько е́сли сде́лаю э́то.
한글 발음야 스마구 빠예하찌 브 라시유, 똘까 예슬리 즈젤라유 에따

то́лько е́сли는 "~해야만"이에요. "러시아로 가다"는 в Росси́ю, 이미 와 있으면 в Росси́и예요.

뜻: 텔레비전에서 봤어요.
러시아어Я ви́дел по телеви́зору.
한글 발음야 비젤 빠 찔리비저루

ви́дел은 "봤어요"(남자), 여자면 ви́дела. встре́тил은 "만났어요"라서 방송으로 본 것에는 쓰지 않아요.

뜻: 그래서 나는 모스크바가 서울보다 더 춥다고 생각해요.
러시아어Поэ́тому я ду́маю, Москва́ холо́днее, чем Сеу́л.
한글 발음빠에따무 야 두마유, 마스크바 할라드녜예, 쳄 세울

холо́днее는 "더 추운"이에요. Поэ́тому는 "그래서"예요.

뜻: 내 생각엔 모스크바가 서울보다 더 커요.
러시아어По-мо́ему, Москва́ бо́льше, чем Сеу́л.
한글 발음빠모이무, 마스크바 볼셰, 쳄 세울

По-мо́ему는 "내 생각엔"이에요.

뜻: 러시아가 한국보다 더 커요.
러시아어Росси́я бо́льше, чем Коре́я.
한글 발음라시야 볼셰, 쳄 까례야

비교할 때는 "더 ~한 + чем(~보다)"를 붙여요.

뜻: 비밀번호
러시아어паро́ль
한글 발음빠롤

명사예요. 와이파이나 문 비밀번호를 말할 때 써요.

뜻: 여기 인터넷 있어요?
러시아어Здесь есть интерне́т?
