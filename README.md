# jw4
글렙의 러시아어 공부

홈(`index.html`)은 매일 보는 요일·달·계절 화면이다. 주 카드나 공부 목록은 넣지 않는다.

## 지난 공부 추가 방법

지난 공부(`past.html`)는 날짜·주 제목 없이, 배운 문장을 한 줄로 이어 붙인 목록이다. 가장 최근에 배운 것이 맨 위에 온다. 음성 강의(플레이어, 듣기 버튼, 연속 재생, PDF 강의 링크)는 넣지 않는다.

1. `/workspace/russian/log.md`에 새로 쌓인 문장을, 기존 카드와 같은 형식으로 만든다: 뜻 / 러시아어(강세) / 한글 발음 / 짧은 설명. 관련 있는 말은 한 카드에 모아도 된다.
2. 새 카드는 `past.html` 목록 **맨 위**(«숨기고 말해보기» 바로 아래)에 넣는다. 이미 있는 카드 순서는 뒤집지 않는다. `build_past.py`의 `NEW_CARDS` 맨 앞에 넣고 스크립트를 다시 돌리면, 11/23 이후 새 카드 + 예전 주 페이지 문장이 같은 최신순으로 다시 만들어진다. 새 카드만 수동으로 위에 붙여도 된다.
3. 주 단위 페이지(`week/그주월요일.html`)는 더 이상 지난 공부의 입구가 아니다. 새 주 페이지를 만들지 않아도 된다. 항목이 10개 미만이라도 다음 주와 합치지 말고, 생긴 만큼 `past.html` 위에 바로 넣는다.
4. `sw.js`의 `CACHE` 버전을 올린다. 미리 담는 주소 목록은 없다.
5. 올리기 전에 미리보기 화면을 보여 주고, 글렙이 확인한 뒤에만 배포한다.

홈 화면(요일, 월 3×4, 계절, «지난 공부» 버튼)과 `body.daily` 글씨 크기는 바꾸지 않는다. 지난 공부 글씨 크기는 `styles.css`의 `body.past`만 조정한다.
