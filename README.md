# jw4
글렙의 러시아어 공부

## 새 주 추가 방법

주는 월요일부터 일요일까지다. 홈에서는 최신 주가 위에 오고, 한 주는 카드 하나다.

1. `week/2026-11-02.html`을 복사해 `week/그주월요일.html`로 저장한다. 제목은 `N월 M째주 (M/D~M/D)`. 구성은 `← 홈`, `숨기고 말해보기`, 핵심 단어(한국어 ↔ 러시아어), 번호 문장(뜻 / 러시아어 / 한글 발음 / 짧은 설명), 단어 표다. 맨 아래에는 그 주 날짜별 강의 링크(듣기 · PDF · 복습)를 둔다. 문장 번호는 1부터 다시 매기고, 러시아어 강세는 그대로 둔다.
2. `index.html`에서 강의 모드 바로 아래, 가장 위에 주 카드 하나를 넣는다. 카드에는 주 제목, 한 줄 주제, 핵심 단어를 넣고, 그 영역을 누르면 `week/그주월요일.html`로 간다. 날짜별 듣기·PDF·복습은 카드 안 `<details>`에 넣고 기본은 접는다. summary는 `강의 듣기 · N개`. 듣기 버튼의 `data-i`는 `AUD` 순서와 같고, 버튼도 그 순서로 이어져 있어야 재생 표시와 연속 듣기가 맞다.
3. `sw.js`의 `CACHE` 버전을 올린다. 미리 담는 주소 목록은 없다.

항목이 10개 미만인 주는 페이지를 만들지 않고 다음 주 페이지에 합친다. 합친 페이지 제목은 두 주를 잇는다. 예: `11월 둘째~셋째주 (11/9~11/22)`.
